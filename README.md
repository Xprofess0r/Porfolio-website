# My Portfolio 🚀

## Live Demo 🌐
Check out my portfolio live at: [view](https://xprofess0r.github.io/Porfolio-website/)

## Installation and Setup 📋

To set up the project locally:

1. **Clone the repository:**
   ```bash 
    git clone https://xprofess0r.github.io/Porfolio-website/
2. **Navigate to the project directory:**
   ```bash
     cd my-portfolio
3. **Install dependencies:**
   ```bash
    npm install
4. **Run the project locally:**
    ```bash
    npm start

## Customization ✏️
This portfolio is fully customizable. To update content such as personal information, skills, and projects, edit the src/portfolio.js file. You can also change the website theme by editing the src/theme.js file.

## Deployment 📦
To deploy the portfolio to GitHub Pages:

**Build the project:**
 ```bash
    npm run build
 ```

**Deploy to GitHub Pages:**
 ```bash
    npm run deploy
 ```
